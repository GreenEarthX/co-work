Construction Notes

Routing: all listed paths are declared under the authenticated layout in frontend/src/App.tsx, except public onboarding/login paths that are not part of the TopBar menu. Several routes also have nested /finance/* aliases, but the current menu uses the root-level paths shown above.
gex_pf_engine: the finance engine remains a backend-side calculation service. It does not define browser menus; finance and pricing screens surface engine-backed workflows through the main platform routes such as /dscr-sensitivity, /finance-plant-builder, /capital-stack, /pricing-lineage, and /ciso-pricing.
Known config drift: backend/app/config/menuArchitecture.ts still contains older labels such as Current, Project Overview, Feedstock Offers, and Demand Pipeline, includes pricing-curves under Commercial, and lacks the frontend gate prerequisites added to the current menu.
