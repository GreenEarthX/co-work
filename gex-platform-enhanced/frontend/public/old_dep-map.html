3. AS-IS vs TO-BE

AS-IS — Current Problems

1 19 files import CUSTOMER_PROJECTS directly — no central data service
2 HS256 symmetric JWT, no refresh tokens, 30min hard expiry
3 x-demo-* headers = role impersonation in dev mode
4 No OIDC — can't federate with Tier-1 banks/insurers
5 Gate IDs hardcoded in 8+ frontend files
6 No workflow enforcement — user can URL-jump anywhere
7 40 routes + 34 modules in one FastAPI monolith
8 Backend event_bus exists but frontend never subscribes

TO-BE — Target Architecture

1 Single useProjectStore() with ABAC + React Query caching
2 RS256 asymmetric JWT + refresh token rotation
3 OIDC claims carry role attributes — no header spoofing
4 Keycloak/Auth0 federation for partner SSO + MFA
5 Gate registry API — frontend reads mapping from server
6 Screens show "locked" state when prereq gates < threshold
7 Bounded contexts: Auth, Project, Commercial, Finance, Ops
8 SSE endpoint → live badges, toasts, dashboard refresh
