1. Current Service Topology

Runtime lanes
browser to engine
Frontend

Vite + React + TypeScript. Authenticated routes use Layout, TopBar, UserRoleContext, and ProjectContext.

Menu + Gate UI

menuArchitecture.ts drives TopBar visibility. GateLock, GatedRoute, and useGateAccess enforce some route locks.

Main Backend

FastAPI app owns auth, ABAC, project truth, gate registry, events, commercial, finance proxies, CISO, and SQLite persistence.

Finance Engine

gex_pf_engine remains browser-isolated. The platform reaches it through finance-model and bankability proxy routes.

Persistence

SQLite-backed demo persistence plus append-only event/audit concepts. Some audit/event pieces are implemented; real-time UI consumption remains open.
